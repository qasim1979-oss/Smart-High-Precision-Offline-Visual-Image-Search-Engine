# 🔍 Smart Offline Local Visual Image Search Engine (Local Lens .exe)

A high-performance, 100% offline Windows desktop application engineered to perform **smart visual similarity searches** across local photo archives, design mockups, and product libraries. Developed with a high-precision structural and color matching engine to ensure relevant results without relying on cloud servers or internet connectivity.

## 🚀 Key Features & Highlights
- **High-Precision Structural Engine:** Combines HSV color histogram analysis (35%) with normalized structural edge template matching (65%) to filter out noise and surface truly relevant matching images.
- **Persistent Smart Caching (`.visual_index_v2.cache`):** Index files remain saved in your target folders. Subsequent runs automatically verify file modification timestamps (`mtime`), making re-indexing blazing fast.
- **Visual Thumbnails & Clickable Paths:** Instantly displays 120x120 pixel image previews of matching local photos alongside clickable file paths that open directly in Windows Explorer.
- **Batch CSV Export:** Export top-ranked relevance matches and absolute file paths into a clean CSV spreadsheet report for client sharing and record-keeping.
- **100% Private & Standalone:** Runs entirely offline on Windows workstations (`.exe`) with zero subscription fees, telemetry, or cloud dependencies.
